# Changelog

## [Unreleased]

- Deliver the turn's text when request-status bookkeeping closes it after the reply was written.

## [0.27.0] - 2026-11-16

- Receive photos and screenshots as native image input, with or without accompanying text, in local and remote Messages chats.

## [0.26.0] - 2026-11-16

- Send each Markdown table as a PNG in its original chat, with ordered text and tappable links. The bundled remote helper stages images on the Messages Mac.

## [0.25.1] - 2026-11-16

- Render replies for phone screens, with readable table rows, lists and links. Match recovered deliveries against the text sent to Messages.

## [0.23.0] - 2026-11-16

- Admit a rostered sender and group participants for the configured agent, retaining per-message identity.

## [0.22.0] - 2026-11-16

- Add a Messages text adapter with direct and group replies, resumable intake and delivery receipts.
