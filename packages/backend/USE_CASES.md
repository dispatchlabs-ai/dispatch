# Backend goals

- **BCK-001 — Reuse native operations:** An authorized consumer composes the package without depending on Web's UI or private installation files.
- **BCK-002 — Preserve ownership:** An operator retains native work and request identities across failures without silently replacing uncertain owners.
- **BCK-003 — Observe/recover deliberately:** A consumer reads authoritative native state; only an explicitly started host owns recovery. Backend never creates a replacement writer.

See [contracts and qualification limits](README.md); accepted future principal and multi-human goals remain in [Web's catalog](../web/USE_CASES.md).
