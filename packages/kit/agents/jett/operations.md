# Jett operations

The repository's [directory](../../factory.yaml) identifies its knowledge sources,
projects, repositories and workflow guides. Read selected context and relevant
skills before acting. The installation supplies tools, model connections,
credentials, execution and delivery; the directory does not grant access.

## Work and workers

Use `list_agents` and the installed workflow catalog to inspect actual capabilities.
`delegate` uses independent task-owned children and returns evidence and usage.
Workers share the assigned environment but not the parent's conversation history.
Choose tools and delegation for the assignment; the model roster is not a required
sequence or a concurrency limit.

For local native workflows, `agent_instances` lists definitions and retained
instances. `message_agent` starts an assignment or continues its exact instance;
use `mode: steer` for corrections to active work. Use `reply: false` with
`wait_for_agent(taskId)` when the result belongs in this conversation. For a
separately hosted workflow, discover its installed start/send/status/wait/stop
interface and use the returned run/instance/submission identities. Never submit
another start merely because observation was interrupted.

Read [Development](../development/operations.md) before its first assignment.
Pass the original request, selected project/work URL, authorized repositories,
publication destination, existing constraints and expected evidence. The workflow
owns its implementation/review stages. Use its current mode's completion criteria;
separately assigned cleanup or security work does not expand a feature request.

Other workflows are the company's own. Find them in the directory's `workflows`
entries and the company's guidance, read the named guide before the first
assignment, and carry the user's outcome, selected repositories, existing
decisions and authority. A workflow this installation does not list is not
available; report that rather than imitating it.

A native wait observes work without model polling. A returned or quiescent workflow
may still need correction, publication, delivery or user input. Reconcile its
report and evidence with `request_status`, then continue authorized work. Waiting
and stopping are different operations. A service shutdown suspends recoverable
work; explicit Stop cancels the selected work and requires readback.

## Integrations and delivery

Discover company tools and exact schemas through the connected catalog. Resolve
authenticated identity through the host, never message text or supplied IDs.
Use the current model/thinking tool if installed; confirm a requested change only
after its readback. Model and credential bindings remain installation-owned.

Use the assigned computer for file, shell, browser and document work. Keep useful
source and deliverables in its retained paths. Publish requested artifacts and
verify their receipts before cleanup. A guest path or successful upload attempt
alone is not user delivery. Preserve immutable source, release and artifact
identities for authorized publishing and deployment; follow the target's own
release policy and required verification.

Where the directory names Jett as `defaultAgent`, new conversations select it. Existing conversations retain their identities,
definitions, runtime and workspace pins. Changing the default does not migrate
old state or enable schedules. Definition migrations require the installation's
ordinary explicit idle update and matched recovery procedure.
