# Web goals

The authorized full replacement retires the previous workspace product, not durable
agents. Implementation/qualification limits are in the [usage guide](docs/usage-guide.md).

## Current replacement scope

- **DSP-004 — Work with agents:** A person selects an authored agent and sends messages and follow-ups in independent native conversations.
- **DSP-010 — Stop owned work:** A person stops the selected native conversation's owned work without cancelling independent recipients.
- **DSP-011 — Resume observation:** A person reopens saved native history after disconnect without resending or resuming execution.
- **DSP-013 — Inspect execution evidence:** A person sees attributed replies, streaming and native tool identities, arguments/results, waits/cancellation and failures in expandable turn-scoped traces.
- **DSP-014 — Retrieve retained material:** A person downloads available native conversation artifacts and supplies retained UTF-8 documents/images using native input blocks, with explicit unsupported formats/model capability.
- **DSP-040 — Integrate a client:** An authorized Web, CLI or channel client uses shared operations and native request identities.
- **DSP-042 — Operate an installation:** An operator composes consumer definitions, authorization and host bindings with Web and native workers.
- **DSP-043 — Operate distributed work:** An operator connects native workers outbound to a central service that alone accesses PostgreSQL.
- **DSP-044 — Preserve state:** An operator retains native durable history and paired definitions/workspaces/artifacts for deliberate recovery.
- **DSP-045 — Diagnose problems:** An operator inspects admission, native ownership and service failures without replacing uncertain executors.
- **DSP-047 — Preserve intent:** Implementers and reviewers verify affected goals against current authorized contracts.

## Accepted future scope (not completed by this UI)

- **DSP-005 — Collaborate:** Multiple human participants share authorized conversations with durable agents.
- **DSP-008 — Coordinate work:** Agents coordinate dependent work through native messaging and recovery, independently of the selected interface.
- **DSP-046 — Obtain independent review:** A requester assigns separate review and receives actionable results under shared authority.
- **DSP-050 — Resolve attention:** A participant resolves work needing input/review independently of execution status.
- **DSP-052 — Preserve agent principals:** The same durable agent retains identity, state and authority across Web, CLI and Slack, concurrently across conversations.

Runner/channel capabilities continue in their own packages; this catalog does not
claim every existing channel is wired to the new Web HTTP adapter. Multi-human
identity/grants, portable principal resolution and full channel composition remain
accepted goals, not a fake login, per-principal queue or a second transcript.

## Explicitly retired old Web surfaces

The authorized replacement retires old workspace implementations/goals DSP-001–003,
DSP-006–007, DSP-009, DSP-012, DSP-015–039, DSP-041, DSP-048–049 and DSP-051:
company enrollment/accounts, mentions/room participants, project/settings/spec UI,
Web-authored agent/skill/provider/evaluation management, old capability/import/export
products. Tool/provider/definition authority moves to consumer-owned native hosts;
retirement here does not remove Runner's tools, authored skills or channel products.
No compatibility APIs or database migrations are provided for the retired product.
