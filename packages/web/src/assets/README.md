# Dispatch brand assets

These original Dispatch SVG assets are distributed with the project under its
[MIT license](../../../../LICENSE). Historical design-source records are retained
privately; using the public repository does not require access to those records.

- `dispatch-logo-horizontal-primary.svg`: horizontal logo for light backgrounds.
- `dispatch-logo-horizontal-inverse.svg`: horizontal logo for dark backgrounds.
- `dispatch-icon-mark-primary.svg`: standalone icon.

Preserve their proportions and the navy/aqua palette. Inter is served locally
through the pinned `@fontsource-variable/inter` package, which retains its own
license. Asset provenance does not import an older application's product scope.
