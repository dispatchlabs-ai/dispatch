# Use cases

- **GC-001 — Conversation:** A user addresses an existing agent in an allowed
  Google Chat space and receives its response in the same thread.
- **GC-002 — Steering:** A follow-up addressed to the app reaches active native
  work as steering, preserving the original definition and thread history.
- **GC-003 — Recovery:** A host restarts with retained native state and resumes
  admitted work and pending delivery without duplicate visible messages.
- **GC-004 — Stop:** An authenticated participant stops the conversation and its
  host-owned execution; a later message can resume with saved history.
- **GC-005 — Host integration:** A company applies its own identity, capability,
  progress and continuation rules while exposing the same CLI-runnable definition.

Not supplied: whole-space message subscriptions, historical message access,
user-authenticated uploads, company credentials or an agent definition.
