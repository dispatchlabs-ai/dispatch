# Workers goals

- **WRK-001 — Reuse native operations:** An authorized consumer composes the package without depending on Web's UI or private installation files.
- **WRK-002 — Preserve ownership:** An operator retains native work and request identities across failures without silently replacing uncertain owners.
- **WRK-003 — Observe/recover deliberately:** A consumer reads authoritative native state and explicitly recovers only after establishing ownership and effect safety.

See [contracts and qualification limits](README.md); accepted future principal and multi-human goals remain in [Web's catalog](../web/USE_CASES.md).
